Dolby Encoding Engine Wrapper

A fast CLI and GUI that wraps ffmpeg and Dolby Encoding Engine for Dolby-certified audio encoding (DD, DDP, AC4, TrueHD).

Download View on GitHub

Windows and Linux builds · always the latest release · All releases & changelogs

Features

Everything deew does in the background so you don't have to fight DEE's XML files.

  • handles Dolby's XML input fuckery and creating the RF64 intermediate in the background, giving you a proper tool

  • runs multiple encodes in parallel for batch encoding (see config)

  • supports WSL path conversion for the Windows version of DEE (see config)

  • automatic sample rate conversion using ffmpeg's soxr resampler in case of an unsupported sample rate

    • for DD/DDP/AC4 unsupported rates will be converted to 48 kHz
    • for TrueHD unsupported rates will be converted to 48 kHz if source sample rate is lower than 72 kHz, otherwise will be converted to 96 kHz

  • automatic channel swapping for 7.1 sources (DEE swaps Ls Rs with Lrs Rrs for some reason)

  • automatically compensates for DEE's 256 sample delay (DD and DDP encoding)

  • works even with video inputs

  • versatile delay option that supports ms, s and also frame@fps formats, parsing delay from filenames also supported

Get started

deew ships as standalone builds for Windows and Linux, both as a command line tool and as a desktop GUI. You can also build it from source.

Windows 10 / 11

Download the builds, no installer needed.

CLI

The command line tool.

deew.exe

GUI

The desktop app. Put it in the same folder as deew.exe.

deew-gui.exe

Web UI

The GUI in your browser, e.g. for a server. Put it in the same folder as deew.exe.

deew-web.exe

scoop / choco / winget

Package manager installs are not available yet.

WIP

Linux

Standalone binaries for x86-64 Linux.

CLI

The command line tool.

deew

GUI

The desktop app. Put it in the same folder as deew.

deew-gui

Web UI

The GUI in your browser, no WebKit needed (e.g. for a server or NAS). Put it in the same folder as deew.

deew-web

Make the downloads executable:

chmod +x deew deew-gui deew-web

The GUI needs the WebKitGTK runtime: libwebkit2gtk-4.1-0 on Debian/Ubuntu, webkit2gtk4.1 on Fedora, webkit2gtk-4.1 on Arch.

Build from source

Works on Windows, Linux and macOS with a Rust toolchain.

cargo install deew
