deew 5.0.0 · how the tools are wired

deew tool chain

deew itself never touches audio. It probes the input, then chains ffmpeg, truehdd, dee_shim and the DEE command line tools through temp files and one pipe, with the options shown below. Placeholders are in capitals: IN, TI (track index), TEMP/NAME, OUT, B (bitrate), P (DRC profile).

external tool file / data deew only in some cases

The whole chain

Three lanes: probing (always), the channel path (DD, DDP, TrueHD, AC4, AAC) and the Atmos path (ddp-atmos, thd-atmos, ac4-atmos). Both paths end in one DEE encoder, wrapped in dee_shim when the format needs it.

DDP profiles

--ddp-mode picks the profile of 7.1 DDP (5.1 and below are not affected), --ddp-atmos-mode the profile of ddp-atmos. Without the option deew uses the config's [default_modes].

The default bitrate of each profile is set in the config (ddp_7_1_standard, ddp_7_1_bluray, ddp_atmos_streaming, ddp_atmos_standard, ddp_atmos_bluray), deew -lb lists every allowed bitrate.

Every block and its options

The exact argument lists deew builds, in order. -la prints the same commands with your real paths.

ffprobe

external · every input

Runs once per input before anything else. Its JSON decides the layout, the bitrate table, the Atmos checks and the progress total.

In

  • the input file

Out → deew

  • audio stream TI: codec, profile (Atmos?), channels, channel layout, sample rate, bit depth
  • duration (progress total, decode length check)
ffprobe -v error -print_format json -show_format -show_streams IN

ffmpeg · convert

external · channel formats

Turns track TI into the PCM wav DEE reads, in DEE's channel order. Skipped when the wav is already in TEMP from a run with -k.

In

  • IN, any format ffmpeg reads

Out

  • TEMP/NAME[.variant].wav, RF64
  • stderr time= → progress bar
ffmpeg -y -drc_scale 0 -i IN
       -map 0:a:TI                                   # when no filter is needed
       -c pcm_s16|24|32le                           # input bit depth, 32 when resampling
       -filter_complex '[a:TI]PAN'                   # reorder / silent LFE / TrueHD downmix
       -filter_complex '[a:TI]PAN,aresample=resampler=soxr'
         -ar 48000|96000 -precision 28 -cutoff 1 -dither_scale 0   # rate change
       -rf64 always TEMP/NAME.wav

ffmpeg · copy to pipe

external · Atmos from a container

truehdd only reads raw TrueHD, so for mkv / mka / m2ts ffmpeg copies the track unchanged and streams it into truehdd's stdin. Not used for a raw .thd.

In

  • IN container, track TI

Out

  • raw TrueHD on stdout → truehdd stdin
  • only the exit code counts (timestamp warnings are ignored)
ffmpeg -v error -nostdin -i IN -map 0:a:TI -c copy -f truehd -

truehdd

external · Atmos formats

Decodes the Atmos presentation into a DAMF master: the object audio plus its metadata. Afterwards deew checks that an Atmos presentation was found and that the decoded length matches ffprobe's duration.

In

  • IN (raw .thd) or - (stdin from ffmpeg)

Out

  • TEMP/NAME.atmos, .atmos.metadata, .atmos.audio
  • NAME.caf instead when there is no Atmos (the job fails)
  • JSON lines on stdout → frame count, progress
truehdd decode --presentation 3 --json --output-path TEMP/NAME IN|-

dee_measure_loudness

DEE · only with -mo or -dn

A separate loudness pass. With -dn, deew then writes your dialnorm into the manifest and hands it to the encoder, which skips its own measurement. Doesn't take 7.1, and has no --temp-dir.

In

  • TEMP/NAME.wav

Out

  • TEMP/NAME.loudness.json
  • its own 0–100% progress step, measured dB
dee_measure_loudness --progress 1 --overwrite 1 --input-format wav -i TEMP/NAME.wav
                     --output-manifest TEMP/NAME.loudness.json

DEE encoders

DEE 6.7 · from the dee folder

Every encode starts with --progress 1 --overwrite 1 and ends with the delay and temp options. DEE's [===>] N % lines drive the bar; [Source loudness] shows the measured dB.

In

  • NAME.wav or NAME.atmos
  • loudness.json with -dn

Out

  • OUT in the output folder
  • AC4: TEMP/NAME.ac4.json manifest
  • TrueHD: .mll / .thd.log.html (removed, log kept with -kl)

DD · DDP (≤ 5.1, and 7.1 with --ddp-mode bluray)

dee_ddp_encoder --progress 1 --overwrite 1 --input-format wav -i TEMP/NAME.wav -o OUT
                -e dd|ddp|bluray:drc_profile=P[:lfe_on=0] --data-rate B
                -c mono|stereo|5.1                      # DEE downmixes (-dm, or 7.1 → 5.1 for DD)
                --loudness-management measure_only [--input-manifest TEMP/NAME.loudness.json]
                [--start S | --add-silence S:0] --temp-dir TEMP/dee-PID-INDEX

AC4

dee_ac4_encoder --progress 1 --overwrite 1 --input-format wav -i TEMP/NAME.wav -o OUT
                --output-manifest TEMP/NAME.ac4.json --data-rate B -e drc_profile=P
                -c stereo|5.1 --loudness-management measure_only [--input-manifest …]
                [--start S | --add-silence S:0] --temp-dir TEMP/dee-PID-INDEX

AAC

dee_aac_encoder --progress 1 --overwrite 1 --input-format wav -i TEMP/NAME.wav -o OUT
                -e aaclc --data-rate B --loudness-management skip     # DEE downmixes to 2.0 itself
                [--start S | --add-silence S:0] --temp-dir TEMP/dee-PID-INDEX

TrueHD (DRC other than none)

dee_dthd_encoder --progress 1 --overwrite 1 --presentation 2ch|6ch|8ch:drc_profile=P

dee_shim

external · in front of a DEE encoder

Loads the untouched DEE encoder (--binary) into its own process and patches it in memory. Shim options go before --, DEE's own options after it. deew removes DSHIM_LOG, DSHIM_LOG_LEVEL, DSHIM_LOG_FORMAT, RUST_LOG and DEE_SHIM_* from its environment.

Needed for

  • ddp-atmos, thd-atmos
  • TrueHD with DRC none
  • 7.1 DDP standard profile, 7.0 DDP

Errors

  • exit 2: usage error, 3: lever not applicable (nothing written)
  • deew shows its first error: line

DDP Atmos

dee_shim ddpjoc_encoder --binary dee/dee_ddpjoc_encoder --layout 5.1|7.1/eac3|7.1 --oamd-as-is on --bitrate B --
         --progress 1 --overwrite 1 -e ddpjoc|bluray:drc_profile=P
         --input-format atmos_mezz -i TEMP/NAME.atmos -o OUT [--start S | --add-silence S:0]

TrueHD Atmos

dee_shim dthd_encoder --binary dee/dee_dthd_encoder --oamd-as-is on --as-is on --drc P --
         --progress 1 --overwrite 1 --presentation atmos:number_of_elements=16:legacy_authoring=0
         --input-format atmos_mezz -i TEMP/NAME.atmos -o OUT
         [--start S | --add-silence S:0] --temp-dir TEMP/dee-PID-INDEX

TrueHD, DRC none

dee_shim dthd_encoder --binary dee/dee_dthd_encoder --drc none --
         --progress 1 --overwrite 1 --presentation 2ch|6ch|8ch:drc_profile=film_light   # placeholder, the shim's --drc wins
         --input-format wav -i TEMP/NAME.wav -o OUT [--start S | --add-silence S:0] --temp-dir TEMP/dee-PID-INDEX

deew between the blocks

deew

What deew does with the files and output streams that pass through it.

Reads

  • ffprobe JSON
  • ffmpeg stderr (time=), truehdd JSON lines, DEE stdout (N %, measured_loudness)
  • each tool's exit code and last stderr line

Writes

  • the dialnorm into loudness.json (-dn)
  • progress events to DEEW_EVENTS_FILE (GUI, web)
  • NAME.deew-log.html with -kl

Removes

  • TEMP/dee-PID-INDEX after every job
  • wav / atmos / json temp files unless -k
  • partial output on Ctrl-C
